# content/

Игровой контент Wildforge: только данные, без кода. Сервер загружает и проверяет
эти файлы при старте и отправляет определения клиенту при входе. Клиент берёт
отсюда текстуры.

| Файл | Что описывает |
|---|---|
| `items.json` | предметы. `type`: `material`, `potion` (`heal`), `weapon` (`attack`), `armor` (`defense`), `tool` (`tool` + `tier`). `stack` — размер стака, `color` — цвет иконки и модели |
| `recipes.json` | рецепты: `result`, `qty`, `ingredients` {предмет: количество} |
| `resources.json` | добываемые узлы: что дают (`item`), чем добываются (`tool`, `min_tier`), сколько раз (`charges`), через сколько секунд появляются снова (`respawn`), модель и текстура, где растут (`spawn`: тип земли и шанс, `min_distance` от центра, где 0 — центр, 1 — край). Чем выше запись в файле, тем выше её приоритет при генерации |
| `enemies.json` | враги: статы и их рост с уровнем, `min_level`, модель (`slime`, `wolf`, `humanoid`), текстура, цвет, масштаб, дроп |
| `world.json` | размер мира, радиус города, число врагов, время респавна, слоты инвентаря, стартовый инвентарь |
| `textures/` | бесшовные PNG 128×128. Генерируются командой `go run ./cmd/texgen` в папке `server/`, но их можно заменить своими |

Типы земли для `spawn`: `grass`, `forest`, `sand`, `road`, `rocky`.
