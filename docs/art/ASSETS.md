Для char_adventurer, enemy_wolf, enemy_skeleton, enemy_ogre и gear нужны отдельные UV-атласы по размерам таблицы моделей. Их создают после UV-развёртки. Материалы cloth/metal/fur служат источниками поверхности и поддерживают существующие процедурные модели.

Текущий клиент накладывает tint на многие материалы. Слишком насыщенная исходная текстура приведёт к двойному окрашиванию. Для готовых цветных атласов импорт должен использовать белый tint.

## Интерфейс и эффекты

| ID | Итоговый формат | Требование |
|---|---|---|
| ui_panel_iron | PNG RGBA 128² | рамка под 9-slice, 12 px поля, прозрачная середина |
| ui_slot | PNG RGBA 64² | общий стиль ячейки, отдельные normal/hover/pressed/disabled |
| ui_portrait_adventurer | PNG 128² | тот же герой, лицо 3/4, нейтральный фон |
| ui_item_icons | отдельные PNG RGBA 64² | меч, инструменты, броня, зелья, материалы из items.json |
| ui_cursor | PNG RGBA 32² | читаемая точка нажатия |
| fx_hit | PNG RGBA 64² | 4–6 кадров короткого удара |
| fx_flame | PNG RGBA 128² на кадр | 4–6 кадров, совпадающая точка крепления |
| fx_crystal | PNG RGBA 64² | редкие слабые искры |

Мини-карта строится по реальному миру. Надписи, числа, полоски и активные состояния создаются UI-кодом. Эффекты попадания и добычи синхронизируются с существующими игровыми событиями.
